# Political Planner – Political Event & Field Operations Platform

A mobile-focused platform for managing political events, meetings, members, tasks, grievances, field activities, and operational expenses through integrated backend services.

## Live Application

- **Apple App Store:** [Political Planner](https://apps.apple.com/in/app/political-planner/id6796329245)

## Project Overview

Political Planner helps political organizations and individuals coordinate field operations, manage scheduled activities, track grievances, and organize operational information through a mobile application and backend APIs.

## Key Features

### Meetings & Event Management
- Meeting, event, and member management.
- Task assignment and field activity tracking.
- Scheduled activity management and reminders.
- Snooze functionality for meetings, tasks, and reminders.

### Grievance Management
- Grievance creation and tracking.
- Issue assignment and deadline management.
- Resolution tracking and status updates.

### Travel & Expense Management
- Travel and operational expense tracking.
- Expense-related reporting.
- Organized management of field operation expenses.

### Gallery & Media Management
- Gallery and media management APIs.
- MinIO object storage integration for media files.

### Mobile Application Integration
- Deep linking for navigation to specific app screens and workflows.
- REST API integration to support mobile application features.
- Backend services for mobile user workflows.

### Backend Engineering
- REST API development using JavaScript, Node.js, and Express.js.
- Authentication, authorization, and request validation.
- Optimized database operations.
- Integration with production backend services.
